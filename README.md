# GimmeTheSauce

Find public research on app and SaaS founders in your AI assistant. Ask which products a founder built, look up a specific launch or pricing decision, or compare what two founders said with links to the original sources.

## Connect

Add `https://gimmethesauce.com/mcp/directory` as a remote MCP server using Streamable HTTP. It is free to use and requires no account or API key. Cursor users can also copy the server entry from [mcp.json](./mcp.json) into their MCP configuration.

## Try it

- “Who built DataFast?”
- “Find a source on activation from Marc Lou.”
- “Compare Marc Lou and Pieter Levels on launches. Include a source from each.”

The `find_mentors` tool finds founders by name, product or topic. Pass the returned research ID and a topic to `search_sources` to get public source links and summaries. These tools are read-only and do not access private chats, app projects or account data.
